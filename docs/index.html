Attention Explorer

A 0.8M-parameter character-level GPT trained on Shakespeare. Pick a character and see which earlier characters each attention head reads from when predicting what comes next. The model runs in your browser, so you can also cut heads and watch what breaks.

Cut a head

Each square is one head reading your text: row = the character doing the looking, column = the character looked at. Click a square to trace that head on the page above. Cut it and every number on this page, generation included, comes from the model without it.

Make it write

The model continues your text one character at a time with whatever heads are still in. Run it once with the full cast, then cut the previous-character heads and run it again.

Related work

None of these techniques is new. This reproduces known results on a model small enough to run in a web page. The difference from the tools below is that you can cut heads and generate here, as well as look.

  • Michel, Levy & Neubig 2019. Are Sixteen Heads Really Better than One? Most heads can be removed one at a time with little loss. Fig. 2 agrees.
  • Voita et al. 2019. Analyzing Multi-Head Self-Attention: Specialized Heads Do the Heavy Lifting. Positional heads that attend to adjacent tokens, like layer 0 here.
  • Elhage et al. 2021. A Mathematical Framework for Transformer Circuits; Olsson et al. 2022. In-context Learning and Induction Heads. Previous-token heads are the first half of an induction head.
  • nostalgebraist 2020. interpreting GPT: the logit lens; Belrose et al. 2023. Eliciting Latent Predictions from Transformers with the Tuned Lens. The method behind Fig. 3.
  • Vig 2019. BertViz; TransformerLens. The standard tools for this on real models.
  • Karpathy 2023. Let's build GPT. The architecture and training setup.
